
# Web Scraping with Python

This repository contains my web scraping practice and projects using Python. It focuses on extracting useful information from websites, parsing HTML content, and collecting structured data for analysis.

## Topics Covered
- Web scraping fundamentals
- HTML parsing
- Extracting text and links
- Inspecting HTML elements
- Data extraction from websites
- Collecting structured data
- Saving scraped data into CSV files
- Basic web data automation

## Libraries Used
- Python
- Requests
- BeautifulSoup
- Pandas

## Purpose
To learn how to collect real-world data from websites and build a foundation for data analysis, data science, and automation.

Learning and exploring one project at a time!
